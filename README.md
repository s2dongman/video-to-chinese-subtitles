# 视频中文字幕制作 Skill

给 Agent 一个视频链接或本地文件，自动识别语音和画面文字的语言，统一翻译成简体中文，并制作保留原声、避开原字幕的完整视频。

## 使用

将本仓库放到 `~/.codex/skills/video-to-chinese-subtitles`，在支持技能的 Agent 中调用：

> 使用 $video-to-chinese-subtitles，给这个视频制作中文字幕。自动识别语言，使用默认双层字幕效果，直接生成完整视频。

首次安装后如当前会话尚未发现技能，新建会话即可。也可明确要求“先给我5秒样片，确认后再处理全片”。

## 默认效果

- 画面文字译文：对应原文上方，白字黄描边、深色底框。
- 语音译文：原文下方、底部黑边上方，白字黑描边、深色底框。
- 语音字号以1080p画面45号为基准，自动按画幅调整。
- 保留原文、原声与底部黑边；空间不足时以不重叠、可读为优先。
- 分别处理语音与画面文字的语言；中文内容不重复翻译，无法可靠识别则明确标注。

## 能力与依赖

这是 **Agent 编排技能**，不是一个离开 Agent 就能自动翻译任意视频的程序。Agent 负责语言识别、选择 ASR/OCR、校对、中文翻译和布局审阅；配套 Python 脚本负责字幕编译、样片/全片渲染及媒体完整性检查。

基础依赖：Python 3.9+、FFmpeg/ffprobe（含libass、libx264）、中文字体。在线下载可用 yt-dlp；语音识别、OCR 按环境选择本地或已授权服务。无固定付费 API 依赖，不要求提供原语言，也不保证所有语言和低清素材均能可靠识别。
