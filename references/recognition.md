# 获取、自动语言识别与校对

## 获取与环境

先查看 `yt-dlp --help`、`ffmpeg -filters` 与已安装 ASR/OCR 能力；FFmpeg 需有 `subtitles`/libass 和可显示中文的字体。下载示例（仅在可访问且用户授权的来源使用）：

```sh
yt-dlp --no-playlist --write-info-json --write-subs --write-auto-subs --sub-langs all --sub-format vtt -f 'bv*[height<=1080]+ba/b[height<=1080]' --merge-output-format mp4 -o 'work/source.%(ext)s' 'VIDEO_URL'
ffmpeg -i work/source.mp4 -vn -ac 1 -ar 16000 work/asr.wav
```

`all` 在字幕语言很多时会浪费下载或触发限流：可先列出可用字幕，再按检测语言下载相关原文字幕。不要依赖机器翻译字幕作为原文。1080p 是下载默认上限，用户要求保留更高分辨率时调整。

字幕下载失败不必重新下载已完成的视频；网站验证或权限阻塞时保留完成部分，要求最小必要输入（例如本地视频），不绕过访问控制。

## ASR

可选本地 faster-whisper、Apple Silicon 上的 mlx-whisper，或环境已有的可信转写服务。查看所选版本接口，自动识别通常省略 language 或设为 None，而非固定 `ko`、`en`。

不要只用开头 30 秒认定全片语言。对有效语音的不同片段独立检测，记录：片段起止、语言、检测置信度（后端有提供时）与证据。静音、歌曲、很短的词和口音可能造成低置信度；扩大上下文并复核。不要编造后端没有提供的置信度。

多语言视频按语言变化分段识别，换算回全片时间；分块时使用适量重叠上下文并去重边界重复句。提示词不得凭猜测植入人名或语言。背景音乐附近的重复句、无语音片段的长段文本应列为疑点，而非直接翻译。

## OCR

可选 macOS Vision、PaddleOCR 或环境已有多语言 OCR。先依据可辨文字/脚本缩小候选识别器，确认后再设语言；不能默认所有视频均为韩语。多个文字系统可分别识别。记录框坐标时统一为原画面像素、左上角原点，勿混用 Vision 的左下角归一化坐标。

按文字相似度、位置和时间连续性去重，不跨剪辑合并。保留少量变化（数字、人名、否定词）而非误并。低清、小字、动态描边可放大裁切复核。OCR 可用于校对画面对白，但不能证明与声音完全一致。

## 翻译记录

维护带全片时间的语音、画面两组记录。保留原文、简体中文、来源（ASR/原字幕/OCR）、语言、疑点状态；不用把原始敏感内容打包到技能仓库。

画面已有中文且声音也为中文时，不再叠加同样内容。只有中文语音而没有可读字幕时，可以生成一条中文转写字幕。混合句中的外语部分翻译，姓名、品牌与技术标识按语境保留。
